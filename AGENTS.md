# AGENTS.md — [Gestionnaire Variantes]
Es tracta d'aplicació backend multiusuari monolítica que permeti a un equip de persones que es dedica a codificar productes afegir a la codificació un codi de declinació que permeti classificar les variants.
S'ha de processar tota una base de dades de codificació i fer un interficie GUI per validacions manuals dels resultats.
## Stack i estructura 
Backend Python amb GUI multiusuari en Windows Server 2019/RDS, sobre la instància existent SQL Server 2017 Express de producció. Proves locals a SQL Server 2019 Express no canvien el disseny ni autoritzen dependències exclusives de 2019. Base exclusiva del projecte: `VARIANTS_PARKOD`, esquema `dbo`; no esquema personalitzat `variants` ni migració de motor prevista. Disseny net i modern. Codi, configuració tècnica, logs i debug en anglès; GUI i missatges externs en francès.
El fitxer 'docs/Parkod.md' conté el model funcional decidit per la nova base de dades. El diagrama i el diccionari de camps són a 'docs/DATA_MODEL.md' i els arguments a 'docs/DECISIONS.md'. Llegiu-los i distingiu els acords confirmats de les propostes tècniques pendents de validació.
## Ordres 
El programa es podrà executar en mode interactiu i en mode batch (com a tasca planificada windows). 
## Convencions
Disseny net i modern. Estandards de Python a seguir. Estandars de SQL a seguir. La programació, parametrització tècnica, logs i tot els missatges de debug i tècnics serà en llenguatge angles. Les interfícies GUI i els missatges al mon exterior seran en llenguatge Francés. 
- Prioritzeu SQL estàndard quan sigui possible, sense prometre portabilitat ANSI/ISO completa ni substituir mecanismes SQL Server aprovats. Manteniu a SQL integritat, controls compartits de sessió/permisos/reserva, concurrència i atomicitat de dades/auditoria; no els traslladeu a Python per aparent portabilitat. Procediments acotats, transaccions curtes i responsabilitat clara d'errors/COMMIT/ROLLBACK; eviteu SQL dinàmic o complexitat innecessaris.
- Documenteu cada dependència específica de SQL Server, de sintaxi o comportament, amb comentaris en anglès al punt d'ús del codi SQL: característica, motiu i garantia a preservar si se substitueix. Incloeu-hi bloquejos, aïllament, collations, tipus/sintaxi i índexs, no només paraules clau T-SQL. Manteniu l'inventari a `docs/DATA_MODEL.md` §6.12 i els arguments a `docs/DECISIONS.md`. Documentar no aprova noves dependències ni autoritza modificar SQL legacy.

- **Abans de plantejar una decisió o demanar una confirmació**, comprova si ja està resolta a la conversa disponible, `docs/DECISIONS.md`, `docs/Parkod.md`, `docs/DATA_MODEL.md` i `MEMORY.md`. Cerca també formulacions equivalents, no només paraules literals.

- Distingeix una **decisió pendent** d'una **implementació, prova o documentació pendent**. Que el SQL encara no existeixi o no s'hagi provat no invalida l'acord de disseny ni autoritza implementar-lo.
